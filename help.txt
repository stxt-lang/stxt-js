Inicializar el proyecto con: npm install

Compilar el proyecto (src -> out): npm run build
Compilar en modo watch (recompila al guardar): npm run watch
Lint: npm run lint

******
Tests
******

npm test

Compila, pasa eslint y ejecuta mocha sobre out/test/**/*.test.js (src/test/).
Son tests de regresión contra el corpus real del proyecto hermano ../stxt-web:

  - schemas.test.ts   todos los .stxt de stxt-web/.stxt cargan como schema o template
  - documents.test.ts todos los .stxt de stxt-web/docs, /es y /en parsean y validan
                      sin errores contra esos schemas; y un schema y su template
                      del mismo namespace validan exactamente igual
  - writer.test.ts    lo que escribe NodeWriter (tabs y 4 espacios) vuelve a parsear
                      dando el mismo árbol

No se copia el corpus aquí a propósito: la gracia es fallar cuando la implementación
se separa de los documentos reales, no de una copia congelada. Si stxt-web no está
al lado, los tests quedan como "pending" en vez de fallar; para indicar otra ruta:

  STXT_WEB=/ruta/a/stxt-web npm test

  ## Referencia rápida

```bash
npm version X.Y.Z --no-git-tag-version     # 1. package.json + package-lock.json
#   + entrada en ../stxt-vscode/stxt/CHANGELOG.md
npm test                                    # 2. build + lint + 224 passing, 0 pending
npm pack --dry-run                          # 3. 115 ficheros, sin out/test ni .js.map
npm publish                                 # 4. inmediato e inmutable
npm view @stxt-lang/core version            # 5. verificar desde el registro
git tag -a vX.Y.Z -m "vX.Y.Z" && git push origin vX.Y.Z      # 6.
#   7. subir el rango en ../stxt-vscode/stxt/package.json + npm install allí
```
